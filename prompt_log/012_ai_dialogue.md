> The connection works, but the **model endpoint is wrong / unavailable**:

```text
GeminiDialogueService: API request failed. HTTP/1.1 404 Not Found
```

This usually means this model name is not valid for your API version/account:

```text
gemini-1.5-flash
```

Google’s troubleshooting docs say a 404 means the requested resource was not found and parameters should be checked for the API version. Their API version docs also distinguish stable `v1` from `v1beta`. ([Google AI for Developers][1])

## Fix 1 — Change the model name

In Unity, select:

```text
Systems
└── DialogueSystems
```

On `GeminiDialogueService`, change:

```text
Model Name = gemini-1.5-flash
```

to one of these:

```text
gemini-2.5-flash
```

or:

```text
gemini-2.0-flash
```

I would try this first:

```text
gemini-2.5-flash
```

Then Play again.

## Fix 2 — Use the stable v1 endpoint

In `GeminiDialogueService.cs`, find this line:

```csharp
$"https://generativelanguage.googleapis.com/v1beta/models/{modelName}:generateContent?key={apiKey}";
```

Replace it with:

```csharp
$"https://generativelanguage.googleapis.com/v1/models/{modelName}:generateContent?key={apiKey}";
```

So now you use:

```text
v1
```

instead of:

```text
v1beta
```

## Also improve the error log

In `GeminiDialogueService.cs`, replace the failed request log with this:

```csharp
Debug.LogWarning(
    $"GeminiDialogueService: API request failed. " +
    $"{request.responseCode} {request.error}\n" +
    $"{request.downloadHandler.text}"
);
```

That way, Unity will show the actual Gemini error body, not only `404 Not Found`.
